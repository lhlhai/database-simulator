# SQL Visualiser-style workbench verification

Preview: http://localhost:5180/database-simulator/

The execution panel now exposes three tabs: Visualize, Schema & Data (3), and Messages. The Schema & Data tab shows a schema rail for users, orders and products and an inline editable users table with 6 rows and 6 columns.

The visual hierarchy remains compatible with the existing simulator: Query Studio and Lessons remain above, execution timeline and operator inspector remain central, and observations/result preview remain below. This is an additive workbench layer rather than a replacement that removes Gold Mine Play mode.
